# FDE Learning Repo

Plain-English study material for the **Forward Deployed Engineer (FDE)** role.

## Start here

Open [`docs/README.md`](./docs/README.md) and follow the numbered guides.

## One-sentence definition

An **FDE** is a strong engineer who sits close to the customer, understands their real problem, and builds working software **inside their environment** so the product actually gets used.

## Repo purpose

Use this repo to:

- prepare for FDE presentations and interviews
- study FDE skills over the next few weeks
- keep notes separate from application code repos
