# FDE words and terms (plain English glossary)

## Role / process terms

**FDE (Forward Deployed Engineer)**  
Engineer who works close to the customer and ships working solutions there.

**Deployment**  
Putting software where users can actually use it (not only on your laptop).

**PoC (Proof of Concept)**  
Small build to prove an idea can work.

**Pilot / MVP**  
First useful version for real users, still limited in scope.

**Production**  
The live environment that matters. Mistakes here hurt real work.

**Onsite / embedded**  
Working at or deeply with the customer team (physically or virtually).

**Stakeholder**  
Person with power or interest in the outcome (sponsor, user, IT, security).

**Scope**  
What you agreed to build. Scope creep = endless extras.

**Runbook**  
Simple instructions for operating the system when you are not around.

**Handoff**  
Passing ownership to customer ops or internal product team.

**Productize**  
Turn a one-customer solution into a reusable product feature.

## Technical terms FDEs hear daily

**Integration**  
Connecting two systems so data/actions flow between them.

**API**  
A doorway for software to talk to other software.

**AuthN / AuthZ**  
Authentication = who are you? Authorization = what are you allowed to do?

**SSO**  
Single Sign-On. One company login for many apps.

**ETL / ELT**  
Moving and reshaping data between systems.

**Latency**  
How long something takes. High latency = slow.

**Throughput**  
How much work a system can handle in a time period.

**Observability**  
Ability to see what the system is doing (logs, metrics, traces).

**SLA**  
Service promise (for example uptime or response time).

## AI terms (if the FDE role is AI-focused)

**LLM**  
Large Language Model. The text/reasoning model.

**Agent / agentic AI**  
Software that can decide steps and call tools to reach a goal.

**Tool calling**  
The model asking the system to run a function (search DB, create ticket, etc.).

**RAG**  
Retrieval-Augmented Generation. Find relevant docs, then answer from them.

**BM25**  
A classic keyword search ranking method (not vector search).

**Vector DB**  
Database of embeddings for meaning-based search. Not required for every RAG system.

**Guardrails**  
Rules that stop unsafe or wrong behavior.

**Hallucination**  
Model invents something that is not in tools/docs.

**Eval / evaluation**  
Tests that measure if the agent answers correctly and safely.

**Grounding**  
Forcing answers to come from real sources (docs, DB, tools).

## Business terms

**ROI**  
Return on investment. Did this save money/time enough to justify cost?

**Adoption**  
Are people actually using it?

**Churn**  
Customer leaves / stops paying.

**Expansion**  
Customer buys more after success.

**Time-to-value**  
How fast the customer gets useful benefit after buying.
