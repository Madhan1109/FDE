# Skills you need for FDE (plain English)

Split into must-have, strong-to-have, and nice-to-have.

## Must-have

### 1) Software engineering basics
- Write clean code in at least one language (Python or TypeScript/Java are common)
- Use Git well
- Debug without panic
- Write tests for critical paths
- Understand APIs (REST), JSON, auth headers

### 2) Systems thinking
- See how UI → API → DB → other systems connect
- Spot the real bottleneck (people, process, data, or code)

### 3) Customer communication
- Translate business pain into technical tasks
- Explain technical limits in simple words
- Run meetings that end with decisions

### 4) Delivery under pressure
- Ship a small useful version first
- Cut scope without killing value
- Own the outcome end-to-end

## Strong-to-have (especially for AI FDE roles)

### AI / agent skills
- What an agent is vs a chatbot
- Tool calling
- RAG (retrieval)
- Guardrails / safety
- Evaluation (“how do we know it works?”)
- Prompt design that is testable, not magical

### Data skills
- SQL
- Understanding messy enterprise data
- Basic data quality checks

### Cloud / deploy skills
- Containers (Docker)
- One cloud (AWS / Azure / GCP basics)
- CI/CD idea (build → test → deploy)
- Logs and monitoring basics

### Security awareness
- Secrets handling
- Least privilege
- PII / compliance sensitivity
- Why customer networks are locked down

## Nice-to-have

- Frontend enough to ship a usable UI (Streamlit, React, etc.)
- Infrastructure as code awareness
- Domain knowledge (healthcare, finance, HR, logistics…)
- Workshop facilitation

## Skills map by interview signal

| If they ask… | They want to see… |
|--------------|-------------------|
| “Tell me about a hard customer problem” | Discovery + judgment |
| “How did you deploy it?” | Real ownership, not only local demo |
| “What did you cut from scope?” | Delivery maturity |
| “How do you know quality?” | Tests / evals / metrics |
| “What did product learn?” | Feedback loop to core team |
| “How did you handle security?” | Trustworthiness |

## Honest self-check

Rate yourself 1–5:

1. Coding speed and correctness  
2. Debugging across systems  
3. Explaining to non-engineers  
4. Scoping and shipping  
5. AI/agent fundamentals  
6. Cloud/deploy basics  
7. Security common sense  

Anything at 1–2 is a study priority for the next weeks.
