# Recommended blogs — FDE + Agentic AI (for learning group)

Curated, straightforward reads to share in the FDE chat / learning channel.  
Aligned with the I2I starter study pack (`docs/fde-i2i-starter-docs/`).

## Best single Agentic AI post (share this first)

**[Building effective agents — Anthropic](https://www.anthropic.com/engineering/building-effective-agents)**

- Workflow vs agent
- When *not* to use agents
- Simple patterns (routing, orchestrator, etc.)
- Matches the I2I study notes

## Best for absolute beginners (LLM → tools → loop)

**[A no-nonsense explainer to Agentic AI — Tailscale](https://tailscale.com/blog/agents-are-coming)**

- Plain English: chatbot vs agent = LLM in a loop with tools

**Runner-up:** [What Are AI Agents? — ExplAIn](https://www.explain-ai.org/ai-agents)  
(model + tools + loop + memory)

## Best for FDE role

**[WTF is a forward deployed engineer? — PostHog](https://posthog.com/blog/forward-deployed-engineer)**

- Origin story (Palantir), day-to-day work, why companies hire FDEs

**Runner-up:** [What Is a Forward Deployed Engineer? — DataCamp](https://www.datacamp.com/blog/what-is-forward-deployed-engineer)  
(FDE vs solutions engineer, skills)

1. PostHog (FDE role)  
2. Tailscale (simple agent mental model)  
3. Anthropic (patterns + when to use agents)  
4. OpenAI / IBM (deeper, as needed)

**If you share only one link**
