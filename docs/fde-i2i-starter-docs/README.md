# I2I Agentic AI Starter Guide — Study Pack (plain English)

Source document in this repo:

- [`docs/I2I - Agentic AI Starter Guide _ FDE.docx`](../I2I%20-%20Agentic%20AI%20Starter%20Guide%20_%20FDE.docx)

This folder turns that long guide into short study notes so you can understand it without reading 70+ pages at once.

## How to use

1. **Start with prerequisites** (`00` / `00a`–`00c`) — the DOCX lists these before the main content
2. Then read files **01 → 10** in order (about 15–25 min each)
3. After each file, answer 2–3 questions from the assessment
4. Before interviews/demos, revise [`10-quick-revision-cheatsheet.md`](./10-quick-revision-cheatsheet.md)
5. Prerequisites quiz: [`assessment-prerequisites-mcqs.md`](./assessment-prerequisites-mcqs.md)
6. Full guide practice test: [`assessment-mcqs.md`](./assessment-mcqs.md)

## One-line big idea

**An AI agent** can do a task with an LLM + tools.  
**Agentic AI** means agents can **plan, choose tools/agents dynamically, remember, and collaborate** — not just follow a fixed script.
